# 紫水鸡棋盘 · Swamphen VTT

**Swamphen VTT（简称 SVTT）**是一款正在开发的三维虚拟桌面跑团工具。你可以制作棋子与场景、组织多张地图，并由主持人（DM）开团，邀请玩家（PL）一起游玩。

## 可以做什么

- **制作棋子**：创建基础棋子，定制底座和立牌，导入图片制作轮廓立牌，调整颜色、透明度及金属、磨砂、亚克力等混合材质。
- **搭建场景**：创建地台，涂绘草地、沙地和水面，设置棋子可摆放区域，再组合成地图。
- **准备冒险**：将多张地图组织成一个冒险，为地图设置天空、光照和天气氛围。
- **记录棋子信息**：临时生命值以蓝色分段显示，展开信息牌可编辑备注；棋子实际朝向按90°调整，模型可独立自由旋转。
- **进行跑团**：使用棋子托盘、棋子移动、测距和范围形状等工具，并保存冒险进度。
- **邀请玩家**：DM开放联机后分享邀请码，PL通过邀请码和团密码加入。支持个人棋子归属与操作权限。

## 当前状态

目前提供 **Windows 与 Android ARM64 的 v0.1.2 测试版**，仍处于早期开发阶段。手机已接入触控、镜头、工具及界面适配，最新修复的真机体验与跨设备联机稳定性仍需测试。

从 [GitHub 发版页面](https://github.com/Swamphen-Dammmmmmn/swamphen-vtt/releases/tag/v0.1.2) 下载：

- **Windows**：`svtt-0.1.2-windows-portable.zip`，完整解压后运行“紫水鸡棋盘.exe”，无需安装Godot、Python或.NET。
- **Android ARM64**：`svtt-0.1.2-android-arm64-test.apk`。同包名、同签名的新版APK直接覆盖安装可保留资料；不要先卸载。安卓没有内置更新功能。

Windows用户资料位于软件目录的`userdata`文件夹；搬迁时复制整个目录。完整便携ZIP同时用于首次使用与更新，不再提供独立更新ZIP。设置中的“关于与更新”支持从GitHub下载并显示进度，也支持手动导入完整便携ZIP；发现新版时可通过左上方提示进入。不会自动下载安装，应用更新需要确认并重启，保留上一版本供恢复。GitHub自动生成的源码ZIP不能作为更新包。

v0.1.2不提供v0.1.0更新兼容。旧版若无法识别完整便携包，请解压新版到新目录，将旧目录的`userdata`复制到新版目录后启动；保留旧目录作为备份。安卓资料位于应用私有目录，不会自动同步电脑资料。请备份重要存档；首次缺少棋子缩略图时仍需生成，之后复用缓存。

## 基本使用流程

1. 在“定制”中制作棋子、地台和地图。
2. 在冒险库中创建冒险，将地图加入冒险。
3. 打开冒险进行本地跑团；需要联机时，从冒险菜单进入联机房间。
4. DM设置团密码并开放联机，将邀请码交给玩家；玩家从首页“加团”进入。

PL的身份码用于关联个人棋子权限。在其他设备使用同一身份码可以延续对应权限；更换身份码会影响对已有个人棋子的控制。请妥善保管，不要公开分享身份码。同一身份同时在线时，第二台设备不能加入。

## 从源码运行

源码运行需要 **Godot 4.7.2标准版**。使用Godot打开仓库中的`project.godot`，运行项目即可。仓库附有本机开发启动脚本，但其他电脑可能需要调整引擎位置。

本地开发文档不随此仓库发布，程序内教程目前依赖该本地目录，因此公开源码暂不包含教程正文。
